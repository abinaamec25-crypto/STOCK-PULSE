# StockPulse AI — Enterprise Inventory & Stock Monitoring System
### DefineInfoTech Pvt. Ltd. (DIT) Internship 2026
**Team**: Team T04 | **Project ID**: DIT-P04  
**College**: Anjalai Ammal Mahalingam Engineering College, Kovilvenni, Thiruvarur  
**Scope**: Track product master and stock transactions, calculate balances, identify low/negative stock and unknown codes, and recommend reorders.

## 🚀 Setup & Execution (100% Free & Standalone)
1. Install dependencies: `pip install -r requirements.txt`
2. Run automation pipeline: `python src/main.py`
3. Run automated tests: `python -m unittest discover tests`
4. Start localhost web app: `python app.py` (open http://127.0.0.1:8000)
